# Growth Log

A one-minute daily check-in for health, fitness, learning and habits, with streaks, a 12-week map and trend charts. Installs on a phone as an app and works offline.

**Live app:** https://sagarchakraborty-creator.github.io/growth-log/

- Android (Chrome): open the link, then tap **Install** (or ⋮ → *Install app*).
- iPhone (Safari): Share → *Add to Home Screen*.

Two people, Sagar and Madhumita, each have their own log, goals and habits. Pick the person under **Logging for** at the top.

Entries are saved on the phone only (nothing is sent anywhere). Use **Setup → Backup** to export or import the selected person's log.

## Updating
1. Edit `index.html`, `styles.css` or `app.js`.
2. Change `VERSION` in `sw.js` and `APP_VERSION` in `app.js` to the same new value.
3. Commit and push to `main`. Phones show "New version ready" on next open.
